# CelestiaLab — ทรงกลมท้องฟ้า 3 มิติ (ม.6)

สื่อการเรียนรู้แบบอินเทอร์แอกทีฟ 3 มิติ สำหรับวิชา **โลก ดาราศาสตร์ และอวกาศ ม.6** เรื่องทรงกลมท้องฟ้าและระบบพิกัดทางดาราศาสตร์ **จัดทำโดย ครูพี่นัท**

## โมดูลการเรียนรู้ทั้ง 4 โมดูล

1. **ระบบพิกัดขอบฟ้า (`#/horizon`)** — มุมเงย (Alt), มุมทิศ (Az), ระยะจากจุดเหนือศีรษะ (`z = 90° − Alt`), ทิศ 8 ทิศ, ลากดาวบนโดมและซิงก์ 3 ทาง
2. **ระบบพิกัดศูนย์สูตรฟ้า (`#/equatorial`)** — ไรต์แอสเซนชัน (RA), เดคลิเนชัน (Dec), เวลาดาราคติท้องถิ่น (LST), มุมมองคู่ (อวกาศ + ขอบฟ้า), แผนที่โลกเลือกตำแหน่งผู้สังเกต, รอยดาว, กลุ่มดาวจริง (กระบวยใหญ่, นายพราน, กางเขนใต้) และโซนดาวไม่ตก/ไม่ขึ้น
3. **ระบบพิกัดสุริยะวิถี (`#/ecliptic`)** — สลับได้ทั้งมุมมอง *เส้นทางดวงอาทิตย์บนขอบฟ้า* (ปฏิทิน 12 เดือน, นาฬิกา 24 ชม., เงาผู้สังเกต/วันไร้เงา, เส้นอานาเล็มมารูปเลข 8, แผนที่โลก) และมุมมอง *พิกัดสุริยะวิถี (λ, β)* พร้อมปรับความเอียงแกน `ε`
4. **เปรียบเทียบสามระบบ (`#/compare`)** — ซ้อนพิกัดทั้ง 3 ระบบบนทรงกลมเดียว กำหนดดาวจากระบบใดก็ได้พร้อมตารางแปลงค่าแบบสด, โหมดเน้นระบบเดียว, ดาวตัวอย่าง 6 ดวง และมุมมองคู่

## เทคโนโลยีที่ใช้

- **Vite + TypeScript + Tailwind CSS** (`darkMode: 'class'` รองรับ 3 โหมด อัตโนมัติ / สว่าง / มืด)
- **Three.js** สำหรับฉากทรงกลมท้องฟ้า 3 มิติ (รองรับทั้งเมาส์และหน้าจอสัมผัส)
- **GitHub Actions → GitHub Pages** (`.github/workflows/deploy.yml`)

## การรันในเครื่อง (Local Development)

```bash
npm install
npm run dev
```

สร้างไฟล์สำหรับ Deploy:

```bash
npm run build
npm run preview
```

## การ Deploy ขึ้น GitHub Pages

1. สร้าง Repository บน GitHub ชื่อ **`CelestiaLab`** (ให้ตรงกับ `base: '/CelestiaLab/'` ใน `vite.config.ts`)
2. Push โค้ดขึ้น branch `main`
3. ไปที่ **Settings → Pages → Build and deployment → Source** เลือก **`GitHub Actions`**
4. Workflow `.github/workflows/deploy.yml` จะบิลด์และเผยแพร่ให้อัตโนมัติที่ `https://<username>.github.io/CelestiaLab/`
